# BakBak Website

Marketing website for [BakBak](https://apps.apple.com/in/app/bakbak-fm-in-your-pocket/id6771061849) — FM, in your pocket.

Hosted at [bakbak.rahulgurung.com](https://bakbak.rahulgurung.com) via GitHub Pages.

## Stack

Plain HTML + CSS. No frameworks, no build step.

## Development

```bash
open index.html
```

## Deployment

Push to `main` — GitHub Pages serves it automatically via the `CNAME` record.
